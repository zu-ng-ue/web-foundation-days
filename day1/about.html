About quicknotes

quicknotes is a simple and efficient application designed to help you capture your thoughts instantly. It provides a clean, distraction-free environment for jotting down ideas on the go.

How to use quicknotes

  1. open the quicknotes application.
  2. type your note in the input field.
  3. click the "Add Note" to save it to your list.

Features

  • create and save notes
  • view your notes in one place
  • use keyboard shortcuts for quick actions

keyboard shortcuts

shortcut action
ctrl + N create a new note
ctrl + S save the current note
