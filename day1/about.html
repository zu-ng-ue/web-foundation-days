About quicknotes

quicknotes is a simple place to capture ideas,reminders and important notes.

It helps you keep your thoughts organized so you can find them when you need them.

How to use quicknotes

  1. type your note in the note box.
  2. click the add note button.
  3. review your saved notes in the notes list.

Features

  • create and save notes
  • view your notes in one place
  • use keyboard shortcuts for quick actions

keyboard shortcuts

shortcuts actions
ctrl + N create a new note
ctrl + S save your note
